### P0: chaperone check Command

Create `cmd/chaperone/cmd/check.go` with cobra command.

**Acceptance Criteria (REQUIRED):**
- [ ] `chaperone check` runs without error
- [ ] Shows header "Chaperone Security Check"
- [ ] Checks and displays status for each security layer
- [ ] Uses status icons: ✅ (secure), ⚠️ (warning), ℹ️ (info)
- [ ] Shows recommendations section with actionable items
- [ ] Works with or without config file
- [ ] Exit code 0 (informational, not a gate)

**Security Checks to Implement:**

| Check | Logic | Icon |
|-------|-------|------|
| Single-service mode | Always pass | ✅ |
| Upstream TLS validation | Always pass | ✅ |
| Ignore system proxy | Always pass | ✅ |
| Placeholder auth | All services have placeholder? | ✅/ℹ️ |
| Audit logging | config.Audit.Enabled | ✅/ℹ️ |
| Dedicated user | os.Getuid() matches 'chaperone' user | ✅/⚠️ |
| Unix socket | Not yet supported | ⚠️ |
| Bundled CA | Not yet supported | ⚠️ |

**Output Format:**
```
Chaperone Security Check
========================

Layer 1: Credential Isolation
  ✅ Single-service mode: Each instance handles one credential

Layer 2: Process Authentication
  ✅ Placeholder auth: All services have placeholders configured
  -- OR --
  ℹ️  Placeholder auth: Not configured for: openai, anthropic

Layer 3: User/Permission Isolation
  ⚠️  Running as current user (consider dedicated 'chaperone' user)
  ⚠️  Using TCP port (Unix socket not yet supported)

Layer 4: Network Hardening
  ✅ Upstream TLS: Certificate validation enabled
  ✅ System proxy: Ignored for upstream connections
  ⚠️  CA bundle: Using system CAs (bundled CA not yet supported)

Layer 5: Runtime Protection
  ✅ Audit logging: Enabled (/var/log/chaperone/audit.log)
  -- OR --
  ℹ️  Audit logging: Not enabled

Recommendations:
  • Configure placeholder tokens for all services
  • Enable audit logging: chaperone inject --audit-log <path>
  • See SECURITY.md for the full security model
```

**Technical Notes:**
- Use `user.Current()` to get current username
- Use `user.Lookup("chaperone")` to check if dedicated user exists
- Config file is optional - show what's missing if no config
