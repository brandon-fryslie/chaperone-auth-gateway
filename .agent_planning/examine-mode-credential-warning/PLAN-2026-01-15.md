# Sprint Plan: Examine Mode Credential Warning

**Date**: 2026-01-15
**Feature**: examine-mode-credential-warning
**Estimated Effort**: <30 minutes, ~15 lines of code

## Sprint Goal

Add security awareness warnings to examine mode that alert users when real authentication credentials are being transmitted through the proxy.

## Scope

**In scope (this sprint):**
1. Startup security disclaimer - display warning banner when examine mode starts
2. Per-request auth header warning - log WARN when requests contain auth headers

**Explicitly out of scope (future sprints):**
- Credential redaction in examine mode
- Configuration option to disable warnings
- Blocking requests with credentials
- Modifying auth header detection logic
