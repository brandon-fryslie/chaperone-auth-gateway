## Part 1: Keychain Secret Provider

### Goal
Add `keychain:` protocol support to fetch secrets from macOS Keychain.

### Design

**Interface:** Implements existing `SecretProvider` interface
```go
type SecretProvider interface {
    Fetch(ctx context.Context, ref string) (string, error)
}
```

**Credential Reference Format:**
```
keychain:service/account
keychain:chaperone/openai
keychain:myapp/api-key
```

**Implementation Approach:**
- Use `security find-generic-password` command (no external dependencies)
- Parse service and account from credential_ref
- Return password field from keychain
- Handle errors: item not found, access denied

**File:** `internal/secrets/keychain.go`

**Security Considerations:**
- Only works on macOS (return clear error on other platforms)
- Respects keychain access controls
- No caching (keychain handles this)

### Tasks
1. Create `internal/secrets/keychain.go` with KeychainProvider
2. Register keychain: protocol in secrets registry
3. Add unit tests for keychain provider
4. Add integration test (if keychain item exists)
5. Update README with keychain documentation
