Design Notes:
------------
1. Socket path can be specified via:
   - CLI flag: --socket /path/to/socket (highest priority)
   - Config file: [server] socket = "/path/to/socket"
   
2. Socket vs TCP is mutually exclusive:
   - If socket configured, TCP address/port ignored
   - Config validation warns if both present

3. Socket file lifecycle:
   - Remove stale file before Listen (handles crashes)
   - chmod 0660 after creation (owner/group can connect)
   - Remove on graceful shutdown (cleanup handler)

4. Security benefits:
   - No network exposure (local filesystem only)
   - Filesystem permission controls access
   - Group-based access via socket file permissions
