### Note on Signal Handling

The `WaitForShutdown()` method is implemented but not tested in the automated test suite because:
- Difficult to test reliably in unit tests
- Requires OS signal manipulation
- Can be manually tested during integration
- Tests focus on `Shutdown()` method which is the core logic

The implementation is straightforward:
```go
func (m *Manager) WaitForShutdown() error {
    sigChan := make(chan os.Signal, 1)
    signal.Notify(sigChan, syscall.SIGTERM, syscall.SIGINT)
    <-sigChan
    return nil
}
```

This is a standard pattern and very unlikely to have issues.
