# Definition of Done: Security Audit Fixes
Generated: 2026-01-09

## Acceptance Criteria

### P0: Integration Tests for Security Features
- [ ] New file `test/integration/security_integration_test.go` exists
- [ ] Test: Valid placeholder → credentials injected successfully
- [ ] Test: No placeholder in request → request passes through without injection
- [ ] Test: Wrong placeholder → request passes through without injection
- [ ] Test: Audit log entry created after successful injection
- [ ] Test: No audit entry when injection doesn't occur
- [ ] All tests pass with `go test ./test/integration/... -run Security`

### P1: Placeholder Validation
- [ ] `config.Validate()` checks placeholder length
- [ ] Placeholder < 8 chars returns descriptive error
- [ ] Empty placeholder ("") is allowed (backward compat)
- [ ] Unit test in `internal/config/config_test.go` or similar
- [ ] Test passes with `go test ./internal/config/...`

### P2: Warning Level Elevation
- [ ] `handlers.go` logs missing placeholder at WARN level
- [ ] Warning includes service name
- [ ] Warning only fires once per service (not on every request)
- [ ] Verified by code inspection or log output test

### Overall Verification
- [ ] `go build ./...` succeeds
- [ ] `go test ./...` passes (excluding pre-existing failures)
- [ ] Changes committed with descriptive message
