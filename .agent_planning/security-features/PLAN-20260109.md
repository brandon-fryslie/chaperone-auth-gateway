### P1: Placeholder Token Authentication
Require apps to send a placeholder token that Chaperone recognizes and replaces.

**Acceptance Criteria (REQUIRED):**
- [ ] `Placeholder` field added to `ServiceConfig` in `config.go`
- [ ] authHandler checks for placeholder in Authorization header (or configured header)
- [ ] If placeholder matches, inject real credential
- [ ] If no placeholder or mismatch, pass through WITHOUT injection (request goes upstream as-is)
- [ ] Warning logged when no placeholder configured (backward compat)
- [ ] Documentation in SECURITY.md updated

**Technical Notes:**

Config addition:
```go
type ServiceConfig struct {
    // ... existing fields
    Placeholder string `toml:"placeholder"` // Token app sends that we replace
}
```

Config example:
```toml
[services.openai]
host_pattern = "api.openai.com"
auth_strategy = "bearer"
credential_ref = "keychain:openai"
placeholder = "chap_openai_xxxxxxxx"  # App configures this as OPENAI_API_KEY
```

Logic in authHandler:
1. If `svc.Placeholder == ""`: warn once, inject (backward compat)
2. If `svc.Placeholder != ""`:
   - Extract token from request (Authorization header or configured header)
   - If token == placeholder: inject real credential
   - If token != placeholder: pass through unchanged
