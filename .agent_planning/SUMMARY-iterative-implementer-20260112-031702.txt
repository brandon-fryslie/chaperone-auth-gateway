=== USAGE EXAMPLE ===

Config file (.chaperone.toml):
```toml
[[services]]
name = "myapp"
host_pattern = "api.example.com"
auth_strategy = "bearer"
credential_ref = "env:API_KEY"

[services.myapp.run]
command = "node"
args = ["server.js"]
env_file = ".env"
stdout = "inherit"
stderr = "file:/tmp/myapp.log"
```

Run command:
```bash
chaperone run myapp
```

This will:
1. Start proxy on /tmp/chaperone-myapp-<pid>.sock
2. Load .env file
3. Set HTTP_PROXY, HTTPS_PROXY, CHAPERONE_SOCKET, CHAPERONE_SERVICE
4. Spawn node server.js with environment
5. Forward signals to child
6. Exit with child's exit code
