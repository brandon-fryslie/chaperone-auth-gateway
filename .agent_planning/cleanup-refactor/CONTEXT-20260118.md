## Key Decisions Made

### AuditLogger Interface
```go
// internal/audit/logger.go
type AuditLogger interface {
    Log(entry Entry) error
    Close() error
}

func Noop() AuditLogger { return &noopLogger{} }
```

This allows handlers to call `auditLogger.Log()` without nil checks. Handlers now use `audit.AuditLogger` instead of `*audit.Logger`.

### Handler Split Strategy
Split by **concern**, not by size:
1. `connect_handler.go` - MITM decision (connect phase)
2. `policy_handler.go` - Policy enforcement (drop patterns, allowed paths)
3. `auth_handler.go` - Credential injection (strip existing, inject new)
4. `recording_handler.go` - HAR recording
5. `util.go` - Helpers (request ID, client IP)

### Examine Split Strategy
Split by **responsibility**:
1. `logger.go` - Core logging (LogRequest, LogResponse)
2. `tracker.go` - Discovery tracking
3. `report.go` - Summary report generation
