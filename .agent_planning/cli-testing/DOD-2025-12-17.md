# Definition of Done: CLI Test Coverage

## Acceptance Criteria

- [ ] **Init Command Tests**: Tests for `chaperone init` covering:
  - Valid service (openai/anthropic) creates correct config file
  - Invalid service returns appropriate error
  - Overwrite existing file works

- [ ] **Root Command Tests**: Tests for root command covering:
  - Version flag outputs correct version
  - Help flag outputs usage information

- [ ] **Run Command Helper Tests**: Tests for helper functions:
  - `setupLogging()` configures logger correctly for each level
  - `getCAPath()` returns valid paths

- [ ] **All tests pass**: `go test -race ./...` passes

- [ ] **Coverage improves**: Overall coverage increases toward 80% target

## Sprint Scope
Focus on testable CLI code. Skip heavy OS interaction testing (setup.go network commands).

## Out of Scope
- Full `runServer` function testing (requires running server)
- macOS networksetup command testing
- Integration tests requiring real network operations
