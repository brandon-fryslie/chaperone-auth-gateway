# Implementation Plan: Strict Allowlist Mode

**Created**: 2026-01-15
**Topic**: strict-allowlist-mode
**Estimated Effort**: 2-3 hours

## Goal

Remove transparent tunnel fallback and enforce strict allowlist-only mode. Only configured services will be proxied; all other connections will be rejected with audit logging.

## Current State

- `internal/proxy/handlers.go:86-87` - Transparent tunnel fallback for non-configured domains
- Audit logging exists with event types defined in `internal/audit/logger.go:14-21`
- Service registry correctly identifies configured vs non-configured domains via `ShouldMITM()`

## Changes Required

### 1. Add Audit Event Type (5 min)

**File**: `internal/audit/logger.go`

Add new event constant:
```go
EventDomainBlocked = "domain_blocked"
```

Add after line 21 with other event types.

### 2. Replace Transparent Tunnel with Rejection (10 min)

**File**: `internal/proxy/handlers.go`

**Current code (lines 86-87)**:
```go
log.Debug(reqCtx, "using transparent tunnel for non-configured domain", "host", host)
return goproxy.OkConnect, host
```

**New code**:
```go
log.Warn(reqCtx, "rejecting non-configured domain", "host", host)
return goproxy.RejectConnect, host
```

### 3. Add Audit Logging for Blocked Domains (20 min)

**File**: `internal/proxy/handlers.go`

Need to inject audit logger into connectHandler and log blocked domains.

**Step 3a**: Modify function signature to accept audit logger:
```go
func connectHandler(registry service.ServiceRegistry, certStore *GoproxyCertStore, auditLogger *audit.Logger, logger *slog.Logger)
```

**Step 3b**: Log rejection before returning RejectConnect:
```go
auditLogger.Log(reqCtx, audit.Entry{
    Event:    audit.EventDomainBlocked,
    Host:     host,
    Outcome:  "blocked",
    Detail:   "domain not in service registry",
})

log.Warn(reqCtx, "rejecting non-configured domain", "host", host)
return goproxy.RejectConnect, host
```

**Step 3c**: Update callers of connectHandler in `internal/proxy/server.go` to pass audit logger.

### 4. Integration Tests (60 min)

Create tests verifying:
- Non-configured domain returns connection refused
- Configured domain continues to work (MITM as expected)
