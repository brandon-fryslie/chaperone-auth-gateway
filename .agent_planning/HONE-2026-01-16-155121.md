## Sharpening Toward

The essence this honing serves:
> A MITM proxy that intercepts HTTPS connections, strips any existing auth headers from requests, and injects the correct credentials - so applications never handle secrets directly.

Core concepts guiding this work:
- Service (configured API endpoint)
- Credential Injection Pipeline (handler chain)
- Secret Provider (pluggable fetch)
- Auth Strategy (pluggable apply)
- Run Mode Lifecycle (invisible proxy)
