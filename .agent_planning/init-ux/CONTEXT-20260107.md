## Key Implementation Details

- All output uses `fmt.Fprintln(w.writer, ...)` for testability (writer can be mocked)
- Line lengths should stay under 80 chars for terminal compatibility
- Use `fmt.Fprintln` for full lines, `fmt.Fprintf` for prompts that expect input
- Use `\n` or separate `Fprintln("")` for blank lines
- Bullet points use `•` character (U+2022)
