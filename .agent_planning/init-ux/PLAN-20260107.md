**Technical Notes:**

**Introduction text (draft):**
```
Chaperone is a local proxy that automatically attaches authentication
credentials to your outgoing API requests. Your applications connect through
Chaperone using standard proxy settings, and Chaperone injects the appropriate
API keys before forwarding requests. This means your applications never have
direct access to your API keys—they stay safely stored and managed by Chaperone.
```

**Overview bullets (draft):**
```
This wizard will:
  • Detect which APIs your application calls and how they expect authentication
  • Let you select and configure each service
  • Securely store your API credentials (Keychain, file, or .env)
  • Generate a chaperone.toml configuration file
```
